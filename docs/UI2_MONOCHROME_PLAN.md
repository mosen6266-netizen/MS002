# MS002 UI 2.0 · 石墨黑极简商务主题

> 开发分支：`ui/v2-monochrome`。此分支是**界面预览**，未合并至 main，未发布正式安装包，不更新 `updates/latest.json`。

## 范围与原则

- 主色系仅使用黑、深灰、浅灰与近白；运行正常、异常、警告状态保留少量有实际意义的语义色。
- 所有组件在 Windows 10/11、100%～200% 显示缩放下保持文字可读、按钮可点击、表格不被遮挡。
- UI 不改变 Engine、Signal JSON-RPC、SQLite 表、账号凭据、授权服务或发送调度。
- 确认真实发送、删除、人工裁决与关闭运行任务等操作不因视觉升级而减少确认步骤。
- 严重错误和待人工核对弹窗必须支持置顶；普通信息窗由现代对话框展示。
- 旧版用户不强制更新。正式发布前须保留稳定版与可恢复的数据备份方案。
- UI2 源码不可修改正式 `main` 更新清单，不可自动触发生产环境发布。

## 第一阶段（本分支已实现的基础）

- `Themes/Monochrome.xaml`：中央颜色、卡片、标签、分隔线语义资源。
- 对现有 WPF 页面进行石墨黑中性色迁移，并保留有意义的绿/红/橙状态。
- 统一主窗口导航间距、标题层级、边框、选中状态及全局排版。
- `Ui2DialogWindow`：自定义暗色确认弹窗，保留原 `MessageBoxResult` 语义（默认拒绝危险操作）。
- `.github/workflows/ui2-preview.yml`：仅此分支自动编译和执行功能回归、WPF 启动/布局检查；不生成正式升级版本。

## 后续阶段（未完成，不得宣称正式版）

1. 用共享 UI2 控件完整统一首页、账号、剧本、运行任务、历史和异常恢复的信息布局。
2. 取代剩余 WPF 原生弹层、文件选择器周边提示及窗口跳转的视觉不一致。
3. 在 Windows 10 的 100/125/150/200% 缩放、窄屏与多显示器环境执行视觉复核。
4. 测试大量账号/群组情况下的列表虚拟化与内存占用。
5. 在隔离备份数据上验证完整桌面操作，再发布**单独**的可选 UI2 安装包。
6. 待明确审核与批准后才允许进入 `main`，不主动改变旧版后台协议。
